## 📋 Project Overview

This project implements an end-to-end **Hand Gesture Recognition System** using a **Convolutional Neural Network (CNN)** trained on the **LeapGestRecog** dataset. The system classifies 10 distinct hand gestures captured via near-infrared Leap Motion imaging, and exposes the trained model through a **modern dark-theme Streamlit web application** with real-time confidence scoring.

| Component | Detail |
|---|---|
| **Task** | Task 04 — SkillCraft Technology ML Internship |
| **Dataset** | LeapGestRecog (Kaggle: gti-upm/leapgestrecog) |
| **Model** | Custom CNN (TensorFlow / Keras) |
| **Input** | 64 × 64 RGB images |
| **Output** | 10 gesture classes with softmax probabilities |
| **Web App** | Streamlit with Plotly confidence chart |

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/<your-username>/skillcraft-task4-hand-gesture-recognition.git
cd skillcraft_task4_hand_gesture_recognition
```

### 2. Create a Virtual Environment (Recommended)

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Download the Dataset

Download **LeapGestRecog** from Kaggle:

```
https://www.kaggle.com/datasets/gti-upm/leapgestrecog
```

Unzip it and place the contents inside `dataset/leapgestrecog/` so the folder structure matches the layout shown above.

> **No dataset?** The notebook automatically falls back to a synthetic dataset that lets you run the entire pipeline without downloading anything.

### 5. Train the Model

Open and run the notebook:

```bash
jupyter notebook train_model.ipynb
```

Select **Kernel → Restart & Run All**. The trained model is saved to `model/hand_gesture_model.h5` and all plots are saved to `outputs/`.

### 6. Launch the Web App

```bash
streamlit run app.py
```

Open [http://localhost:8501](http://localhost:8501) in your browser.

| `04_fist_moved` | 👊 Fist Moved | Closed fist with lateral shift |
| `05_thumb` | 👍 Thumbs Up | Only thumb extended upward |

## 🔬 Methodology

```
Dataset Download (LeapGestRecog — Kaggle)
            │
            ▼
    Image Loading & EDA
    (class distribution, sample grid)
            │
            ▼
    Pre-processing
    (BGR→RGB, resize 64×64, normalise [0,1])
            │
            ▼
    Stratified Train/Val/Test Split
    (72% / 8% / 20%)
            │
            ▼
    Data Augmentation
    (rotation, shift, flip, zoom, brightness)
            │
            ▼
    CNN Architecture
    (3 × Conv-BN-Pool-Dropout blocks
     → GlobalAvgPool → Dense → Softmax)
            │
            ▼
    Training
    (Adam, categorical_crossentropy, 30 epochs
     EarlyStopping + ReduceLROnPlateau + ModelCheckpoint)
            │
            ▼
    Evaluation
    (Accuracy, Loss, Confusion Matrix,
     Classification Report, Sample Predictions)
            │
            ▼
    Deployment
    (Streamlit app — upload image → instant prediction)
```

## 🧠 Model Architecture

```
Input         →  (64, 64, 3)

── Block 1 ──────────────────────────────────────────
Conv2D(32)    →  32 × 3×3 filters, ReLU, same padding
BatchNorm     →  Normalise activations
MaxPool2D     →  2×2 stride  →  (32, 32, 32)
Dropout(0.25) →  Regularisation

── Block 2 ──────────────────────────────────────────
Conv2D(64)    →  64 × 3×3 filters, ReLU, same padding
BatchNorm
MaxPool2D     →  (16, 16, 64)
Dropout(0.25)

── Block 3 ──────────────────────────────────────────
Conv2D(128)   →  128 × 3×3 filters, ReLU, same padding
BatchNorm
MaxPool2D     →  (8, 8, 128)
Dropout(0.25)

── Head ─────────────────────────────────────────────
GlobalAvgPool →  (128,)
Dense(256)    →  ReLU  +  L2(1e-4)  +  Dropout(0.5)
Dense(10)     →  Softmax  →  class probabilities
```

**Total parameters:** ~1.2 million  
**Optimizer:** Adam (lr=0.001, ReduceLROnPlateau)  
**Loss:** Categorical Cross-Entropy

## 🎓 Key Concepts Covered

- Convolutional Neural Networks (CNN)
- Batch Normalisation for training stability
- Dropout for regularisation
- Global Average Pooling (vs Flatten)
- Data Augmentation to prevent overfitting
- Learning rate scheduling (ReduceLROnPlateau)
- Early Stopping with `restore_best_weights`
- Stratified train/test split
- Multiclass classification metrics (precision, recall, F1)
- Model serialisation (`.h5` format)
- Real-time inference in a web application
